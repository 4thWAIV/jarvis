## Reproduce

Use the checkout's installed Python environment and existing signing session. These commands create isolated checks, never live package delivery. Output directories must be fresh because the compiler refuses to overwrite a generated package.

```sh
python docs/planning/high-fidelity-packages/implementation/generate_maximum_story.py
python docs/planning/high-fidelity-packages/implementation/check_presentation_package.py examples/presentations/street/presentation.yaml docs/planning/high-fidelity-packages/implementation/review-acceptance/street --session YOUR_SESSION
python docs/planning/high-fidelity-packages/implementation/check_presentation_package.py examples/presentations/walkthrough/presentation.yaml docs/planning/high-fidelity-packages/implementation/review-acceptance/walkthrough --session YOUR_SESSION

python docs/planning/high-fidelity-packages/implementation/check_presentation_package.py docs/planning/high-fidelity-packages/implementation/maximum-story/source/content.json docs/planning/high-fidelity-packages/implementation/review-acceptance/maximum-json --session YOUR_SESSION
python docs/planning/high-fidelity-packages/implementation/measure_presentation.py
pytest tests/test_presentation.py tests/test_make_package.py tests/test_decision_package.py tests/test_package_author.py tests/test_package_story.py tests/test_author_proof.py
```
