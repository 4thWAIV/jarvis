How 25–47 elapsed hours is modeled

2–4 setup + 2–4 dependency handoff delay + longest worker lane (13–25) + 5–9 release acceptance + 3–5 final review = 25–47 hours.

Handoff delay is scheduling within the dependencies, not extra aggregate effort. Final review is part of the 6–10 integration budget. CI preparation may overlap, but the model conservatively reserves the full release package after integration.
